## Sistema de Notas do Aluno
Programa simples em Python que calcula a média de um aluno com base em duas notas e informa se ele foi aprovado ou reprovado.

---

## Tecnologias
- Python

---

## Como executar

```bash
python app.py
```

---

## Funcionalidades

- Solicita duas notas ao usuário
- Calcula a média automaticamente
- Exibe a média com 2 casas decimais
- Mostra o status do aluno:
  - Aprovado (média ≥ 7)
  - Reprovado (média < 7)

---

## Exemplo

```
Digite a primeira nota: 8
Digite a segunda nota: 6
A media final e: 7.00
Status: APROVADO.
```
